# Predator-Prey and Fishing Impact Model

基于 MATLAB 的捕食—被捕食系统动态模拟项目，比较无捕捞与有捕捞两种情景下种群数量的变化。

## 项目简介

本项目使用 MATLAB 建立并求解一个典型的捕食—被捕食（Predator-Prey）微分方程模型，用于研究两类种群数量随时间的动态变化规律。项目通过设置两组不同参数，对比分析了：

- 无人为捕捞时的种群变化情况
- 存在人为捕捞影响时的种群变化情况

该项目适合作为 MATLAB 常微分方程求解、生态动力学建模和系统演化分析的小型练习项目。

## 研究内容

项目将系统中的两个群体抽象为：

- **食饵（prey）**
- **鲨鱼（predator）**

并通过常微分方程描述两类群体之间的相互作用关系。模型重点分析以下问题：

1. 在自然条件下，食饵和捕食者的数量如何随时间变化；
2. 当人为捕捞或外部干扰存在时，种群数量曲线会发生怎样的变化；
3. 不同参数设定下，系统动态特征有何差异。

## 模型说明

### 1. 无捕捞情景

在 `sharkFish1.m` 中，系统写为：

- 食饵增长项为自身自然增长；
- 捕食作用会抑制食饵数量；
- 鲨鱼在没有足够食物时会自然减少；
- 食饵数量增加会促进鲨鱼增长。

对应 MATLAB 代码中的模型形式为：

- `dy(1)=y(1)*(1-0.1*y(2))`
- `dy(2)=y(2)*(-0.5+0.02*y(1))`

### 2. 有捕捞情景

在 `sharkFish2.m` 中，参数发生变化，体现出外界干预或捕捞影响下的系统变化。对应模型形式为：

- `dy(1)=y(1)*(0.7-0.1*y(2))`
- `dy(2)=y(2)*(-0.8+0.02*y(1))`

与无捕捞场景相比：

- 食饵的净增长率下降；
- 鲨鱼的净衰减更强；

这会影响两个群体的数量变化趋势。

## 文件结构

- `wubulaomain1.m`：无捕捞情景主程序，调用 `sharkFish1.m` 求解并绘图
- `sharkFish1.m`：无捕捞情景下的微分方程模型
- `youbulaomain2.m`：有捕捞情景主程序，调用 `sharkFish2.m` 求解并绘图
- `sharkFish2.m`：有捕捞情景下的微分方程模型

## 运行环境

- MATLAB

## 使用方法

1. 将所有 `.m` 文件放在同一目录下；
2. 在 MATLAB 中打开该项目文件夹；
3. 根据需要运行以下脚本：

   - `wubulaomain1`
   - `youbulaomain2`

4. 程序会自动调用 `ode45` 数值求解微分方程，并绘制两类种群数量随时间变化的曲线图。

## 参数设置

两个主程序使用的初始条件相同：

- 时间区间：`1914 ~ 1923`
- 初始条件：`y0 = [25, 2]`

其中：

- `y(1)` 表示食饵数量
- `y(2)` 表示鲨鱼数量

此外，程序中设置了 ODE 求解精度：

- `RelTol = 1e-6`
- `AbsTol = 1e-6`

## 输出结果

运行项目后，将得到两条随时间变化的曲线：

- 红色曲线：食饵数量
- 蓝色曲线：鲨鱼数量

程序可用于观察：

- 无捕捞时种群的动态演化；
- 有捕捞时系统整体数量水平的变化；
- 参数变化对种群平衡与演化趋势的影响。

## 项目特点

- 采用经典生态动力学思想，模型结构清晰；
- 使用 MATLAB 自带 `ode45` 求解常微分方程，适合作为入门案例；
- 通过两组参数设置实现情景对比，能够直观看到人为干预的影响；
- 适合用于学习微分方程建模、数值求解和结果可视化。

## 局限性说明

- 当前模型较为简化，没有考虑环境容量、季节变化或更复杂的食物链关系；
- “捕捞”影响通过参数变化间接体现，没有单独引入显式捕捞项；
- 结果主要用于趋势分析和教学演示，不代表真实生态系统的精确预测；
- 项目输出以基础曲线图为主，尚未加入相图、平衡点分析或稳定性分析。
